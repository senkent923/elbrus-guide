# Эльбрус.Гид — сайт для начинающих альпинистов

Статический сайт (чистый HTML + CSS + JS, без фреймворков и сборки).
Готов к публикации на GitHub Pages, Vercel, Netlify или любом статик-хостинге.

## Структура

```
index.html         — главная (интро, маршрут, подготовка, цены, форма заявки)
preparation.html   — подготовка
gear.html          — снаряжение
faq.html           — частые вопросы
style.css          — все стили
animations.js      — интерфейс, счётчики, форма заявки
snow.js            — падающий снег (фон)
intro.js           — вступительная анимация (только на главной)
```

## Локальный запуск

Просто откройте `index.html` в браузере — всё работает без сервера.

## Деплой на Vercel

1. Залейте папку в репозиторий на GitHub.
2. На vercel.com → **Add New → Project** → импортируйте репозиторий.
3. Framework Preset: **Other**. Build Command и Output — оставьте пустыми
   (это статический сайт, сборка не нужна). Нажмите **Deploy**.

Заявки отправляются на **senkent923@gmail.com** через почтовый клиент
посетителя (`mailto`). Чтобы письма приходили автоматически в фоне —

блок `fetch(...)` в `animations.js` (адрес письма меняется там же,
